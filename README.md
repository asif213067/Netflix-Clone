# 🎬 Netflix Clone

A responsive **Netflix Clone** built using **HTML, CSS, and JavaScript**, powered by a free movie API. The application displays dynamic movie data, trending titles, and search functionality through a modern Netflix-inspired user interface.

---

## 📌 Overview

This project recreates the look and feel of Netflix while integrating real-time movie data from a free API. It demonstrates API integration, asynchronous JavaScript, DOM manipulation, event handling, and responsive web design to deliver a dynamic and engaging user experience.

---

## ✨ Features

* 🎥 Browse popular and trending movies
* 🔍 Search movies by title
* 📡 Fetch real-time movie data from a free API
* ⚡ Dynamic content rendering
* 📱 Fully responsive design
* 🎨 Netflix-inspired user interface
* 🖼️ Movie posters and details display
* 🚀 Fast and interactive user experience

---

## 🎮 How It Works

1. The application requests movie data from a free movie API.
2. JavaScript processes the API response.
3. Movies are displayed dynamically on the page.
4. Users can browse trending content or search for specific movies.
5. Results update instantly without reloading the page.
